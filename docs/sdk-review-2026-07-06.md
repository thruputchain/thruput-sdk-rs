The bottle-test copy (src/bottle_test.rs:27-43) has the identical hole. So if read-only enforcement ever regresses, the only in-repo tests for it stay green. **Evidence:** tests.rs:26 `let mut outputs = core::mem::MaybeUninit::uninit();` ... :34-45 `sdk::sys::uninit_Invoke(&deployed_addr, &calldata, &[], &sdk::sys::CopyableInvokeInputs { entrypoint_id, gas_limit: u64::MAX, flags: flag }, &mut outputs).unwrap();` — outputs never assume_init'd/checked. **Verifier:** CONFIRMED mechanically and empirically. tests.rs:26 leaves outputs as MaybeUninit::uninit() and tests.rs:34-45 only unwraps the uninit_Invoke syscall result; bottle_test.rs:27-43 is identical.
